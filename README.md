# Repository Advisor

An interactive web application that helps researchers identify suitable research data repositories based on their research needs.

## About

The Repository Advisor is an initiative developed as part of the **CUHK Data Champions Programme**. It helps researchers identify appropriate data repositories through an interactive recommendation system based on repository characteristics and research requirements.

## Project Background

The Repository Advisor was initiated by **Data Matters @ CUHK** as part of the CUHK Data Champions Programme. The project builds upon the repository evaluation matrix originally developed by **Qinqin Zhang** and the **CUHK Data Team**, which served as the foundation for the repository database. Through ongoing collaboration, discussion, and iterative refinement, the repository database, recommendation framework, and interactive prototype have continued to evolve.

## Version 2 Architecture Upgrade ✨
The Repository Advisor has been updated to incorporate the Version 2 recommendation framework, developed through collaboration among project contributors. This update introduces a more structured and maintainable architecture, transitioning from the original single-file implementation to a modular codebase.

### Key Improvements
- **Enhanced Evaluation Framework:** Integrated the finalized repository matrix and recommendation scoring methodology into the application structure.
- **Codebase Consolidation:** Unified overlapping development work and aligned recommendation logic into a single maintained framework within the main branch.
- **Modular Architecture:** Separated application logic, styling, and interface components into a cleaner structure that supports future development, maintenance, and integration efforts.
- **Deployment Continuity:** Version 2 now serves as the primary codebase for the project, enabling future updates to be published through the existing deployment workflow.

## Status

✅ **Version 2 Core Framework Merged.** Version 2 has been integrated into the main branch and now serves as the project's primary architecture.
